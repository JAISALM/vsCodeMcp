HOW TO USE
====================================================================
1. Open krea2_jaisal_sketch.json (FRESH tab). The LoRA node is already set to
   krea2_lineart_v1_fp16.safetensors @ strength 1.0.
2. For each image above: paste its prompt into the positive CLIPTextEncode node
   (node 6), keep the shared negative prompt (node 13), run, and save. Name the
   outputs:
     sketch_walk.png, sketch_jump.png, sketch_title.png
   (The walk image is the MAIN anchor - it is the first frame MiniMax animates from.
   The throw/paper-plane moment is now part of the walk shot's action, so a separate
   throw image is optional.)
3. If a character gets DUPLICATED: re-run with a different seed (the KSampler seed
   widget, node 3) until you get a single stick figure.
4. Stage the best ones into input\ as sketch_1_walk.png, sketch_2_jump.png,
   sketch_3_title.png.
5. Feed them as references (ref_image_0..2) to the MiniMax H3 R2V workflow so it
   holds the line-art style across the whole title animation.

KNOWN KREA2 QUIRKS (for the line-art style):
- Krea2 tends to DUPLICATE the character — the prompts say "ONLY ONE character, no
  duplicates" and the negative reinforces it. If it still duplicates, re-run with a
  different seed.
- Krea2 may add shading / color fill even in line-art mode — the negative prompt
  pushes against it ("no shading, no color fill, no gradient"). If it still shades,
  lower the Cinematic LoRA strength or drop it entirely (line-art LoRA alone).
- Keep it to MEDIUM SHOTS ONLY — the negative prompt excludes "wide shot, wide
  angle, establishing shot, extreme close-up".
