HOW TO USE:
1. Open krea2_jaisal_title.json (FRESH tab).
2. Load the underwater shot (refs_water.png) in the LoadImage node (30).
3. Paste the POSITIVE above into the positive node (6), the NEGATIVE into the negative node (13).
4. Queue. The output keeps the underwater scene but shows the title 'The Jaisal Cut'
   (formed from bubbles) instead of the boy. Save as title_card.png.
5. Tuning (Typnosis LoRA = node 32, denoise = KSampler node 3):
   - STR5 (5.0) is the balanced-strong range that reads best for the title (per the
     Typnosis notes: STR1-STR2 is most prompt-faithful; STR4+ gets more stylized and
     compositions converge). If STR5 over-stylizes / distorts the letters, drop to 3.0-4.0.
   - If the title text is garbled: lower denoise to 0.4 (keeps the scene, less text
     distortion) or nudge the LoRA down.
   - If the boy is still there: raise denoise to 0.65-0.7.
   - If the bubbles are too sparse / the letters don't read as bubbles: strengthen the
     bubble wording in the prompt ("each letter built from DENSE clusters of many small
     bubbles") or raise the LoRA a touch.
   - Wavy layout tuning: if the words come out too flat / in a straight line, strengthen
     the wavy wording ("each word drifting at a clearly different height, a gentle S-curve
     across the frame"). If the words get too scattered / the title stops reading as one
     line, soften it ("a SUBTLE gentle wave, words only slightly offset in height, kept
     close enough to read as one title").
   - Size hierarchy tuning: the words are sized 'The' SMALL < 'Cut' MEDIUM < 'Jaisal' BIG
     (the hero word). If 'Jaisal' isn't big enough / not dominant, strengthen it ("'Jaisal'
     MUCH larger than the other words, the clear focal point"). If the hierarchy gets lost
     (all words end up the same size), restate it more forcefully and/or lower denoise a
     touch so the text layout is followed more faithfully.

KNOWN KREA2 QUIRKS (2026-08-28):
- Krea2 CANNOT make a faceless character — it always renders a face. That's fine.
- Krea2 tends to DUPLICATE the character (multiple kids) — the prompts now say
  "ONLY ONE character, no other people, no duplicates" and the negative prompt
  reinforces it. If it still duplicates, re-run with a different seed.
- The bridge prompt now pins the boy ON THE BRIDGE DECK (left side), NOT in the water.

CLIMATE CONSISTENCY (2026-08-29):
- Do NOT change the climate dramatically between shots. Once the rain starts, keep
  ONE moody tone across all the rain/water shots (medium, close-up, water, running).
  The underwater shot must be DARK and moody (matching the rain), NOT bright/sunny.
  A drastic light change between shots breaks continuity and MiniMax won't bridge it.

FACE / IDENTITY CONSISTENCY (2026-08-29):
- Krea2 t2i gives a DIFFERENT face every time the character appears. To lock the
  face, use the IDENTITY workflow `krea2_identity_edit.json` (Krea2 Identity Edit
  v1.2, LoRA `krea2_identity_edit_v1_2.safetensors`, ref_boost=4). Load a good
  reference (the character sheet or a clean close-up) in the LoadImage node, write a
  plain-English instruction, and it regenerates the scene keeping the SAME face.
  This is how we get one consistent character across all the reference images.
