# hongzhuyi/VDEBench


	
		
	
	
		VDEBench: Visual Document Editing Benchmark
	




Edit the requested text or table. Preserve the rest of the document.
VDEBench evaluates instruction-guided image editing on dense Chinese and English document pages. Models must make precise local changes while preserving surrounding text, table structure, typography, and page layout. The benchmark contains 3,506 examples, covering text replacement, addition, deletion, and table content and structure editing.
