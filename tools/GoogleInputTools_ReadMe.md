# Google Input Tools Malayalam (Offline Installer)

> A working offline installer for **Google Input Tools Malayalam**, letting you type in **Manglish** (Malayalam using English letters) and automatically transliterate to Malayalam script.

---
## What is Google Input Tools?

Google Input Tools enables you to type in your language using a standard English keyboard. For Malayalam, you can type **Manglish** (e.g., `ente peru vijith aanu`) and it will automatically convert to **Malayalam script** (എന്റെ പേര് വിജിത്ത് ആണ്).

Though Google no longer officially provides the offline version, this repo offers a working and verified offline installer.

---
## ✅ Features

- 🖥️ **Offline Typing**: No internet needed after installation.
- 🔄 **Phonetic Transliteration**: Converts Roman Malayalam (Manglish) to Malayalam script in real-time.
- 🌐 **Works in All Applications**: Use it in Notepad, Word, Chrome, or any text field.
- 🔤 **Easy Toggle**: Switch between English and Malayalam using a shortcut.

## 🛠️ Installation Guide

> Tested on Windows 7, 8, 10, and 11 (32-bit and 64-bit)

### Step 1: Download & Extract
- Download the `.zip` file of this repository
- Extract it to a local folder

### Step 2: Run Installer
- Double-click on `GoogleInputTools.exe`
- Follow the prompts to install
- After installation, Malayalam language will be added

### Step 3: Enable Malayalam Input
1. Open **Settings → Time & Language → Language**
2. Add **Malayalam (India)** if not already present
3. Under language options, choose **Google Input Tools** if available

## 🧩 Common Issues & Fixes

- **Input Tool Not Appearing**:
  - Restart your PC
  - Reinstall the tool
  - Ensure Malayalam language is added in Windows

- **Not Typing in Malayalam**:
  - Confirm Google Input Tools is the selected method
  - Toggle input using `Alt + Shift`
